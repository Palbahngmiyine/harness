# 자주 틀리는 한국어 맞춤법

## 1. 되/돼 구분

### 규칙
- **되** + 어 = **돼** (줄임)
- '하다'를 넣어서 자연스러우면 '되', '해'를 넣어서 자연스러우면 '돼'

### 예시
| 올바른 표현 | 틀린 표현 | 설명 |
|------------|----------|------|
| 됐다 | 됬다 | '되었다'의 준말 |
| 되었다 | 됬었다 | 과거형 |
| 안 돼 | 안 되 | '안 해'가 자연스러움 |
| 되면 | 돼면 | '하면'이 자연스러움 |
| 되는 | 돼는 | '하는'이 자연스러움 |

### 기억법
> "하/해 테스트": 하→되, 해→돼

---

## 2. 웬/왠 구분

### 규칙
- **웬**: 단독으로 사용 (어찌 된, 어떠한)
- **왠**: '왠지'에서만 사용 (왜인지)

### 예시
| 올바른 표현 | 틀린 표현 |
|------------|----------|
| 웬일이야 | 왠일이야 |
| 웬 떡이냐 | 왠 떡이냐 |
| 왠지 모르게 | 웬지 모르게 |

### 기억법
> "왠지"만 '왠', 나머지는 전부 '웬'

---

## 3. 로써/로서 구분

### 규칙
- **로써**: 수단, 도구, 방법 (by means of)
- **로서**: 자격, 지위, 신분 (as)

### 예시
| 올바른 표현 | 틀린 표현 | 설명 |
|------------|----------|------|
| 펜으로써 글을 쓰다 | 펜으로서 글을 쓰다 | 수단 |
| 학생으로서 책임 | 학생으로써 책임 | 자격 |
| 돈으로써 해결 | 돈으로서 해결 | 수단 |
| 친구로서 충고 | 친구로써 충고 | 자격 |

### 기억법
> 도구/수단→로"써"(쓰다), 자격→로"서"(서다)

---

## 4. 데/대/때 구분

### 규칙
- **데**: 장소, 경우, 일 (의존명사)
- **대**: 말하다의 준말 (~라고 해)
- **때**: 시간

### 예시
| 올바른 표현 | 틀린 표현 | 설명 |
|------------|----------|------|
| 갈 데가 없다 | 갈 때가 없다 | 장소 |
| 아픈 데가 있다 | 아픈 때가 있다 | 부위 |
| 그가 온대 | 그가 온데 | ~라고 해 |
| 먹을 때 | 먹을 데 | 시간 |

### 기억법
> 장소→데, 시간→때, 전달→대

---

## 5. 않/안 구분

### 규칙
- **않다**: 아니하다의 준말 (동사/형용사 뒤)
- **안**: 아니 (동사/형용사 앞)

### 예시
| 올바른 표현 | 틀린 표현 |
|------------|----------|
| 하지 않다 | 하지 안다 |
| 안 하다 | 않 하다 |
| 먹지 않았다 | 먹지 안했다 |
| 안 먹었다 | 않 먹었다 |

---

## 6. 이/히 구분 (부사 형성)

### 규칙
- 받침 없는 형용사 + 이 → 깨끗이
- 받침 있는 형용사 + 히 → 급히
- 예외가 많으므로 암기 필요

### 자주 틀리는 예시
| 올바른 표현 | 틀린 표현 |
|------------|----------|
| 깨끗이 | 깨끗히 |
| 깊이 | 깊히 |
| 많이 | 만히 |
| 일찍이 | 일찍히 |
| 가까이 | 가깝히 |
| 솔직히 | 솔직이 |
| 급히 | 급이 |
| 곱게 | 곱히 |

---

## 7. 맞히다/맞추다/맞다 구분

### 규칙
- **맞다**: 적중하다, 정답이다
- **맞히다**: 맞게 하다 (정답을 맞히다)
- **맞추다**: 비교하다, 조절하다

### 예시
| 올바른 표현 | 틀린 표현 | 설명 |
|------------|----------|------|
| 정답을 맞히다 | 정답을 맞추다 | 적중시키다 |
| 시간을 맞추다 | 시간을 맞히다 | 조절하다 |
| 답을 맞혔다 | 답을 맞췄다 | 정답 적중 |
| 비교해 맞추다 | 비교해 맞히다 | 대조하다 |

---

## 8. 던/든 구분

### 규칙
- **던**: 과거 회상 (~했던)
- **든**: 선택, 무관 (~하든)

### 예시
| 올바른 표현 | 틀린 표현 | 설명 |
|------------|----------|------|
| 먹던 음식 | 먹든 음식 | 과거 회상 |
| 먹든 말든 | 먹던 말던 | 선택/무관 |
| 보던 영화 | 보든 영화 | 과거 회상 |
| 가든 오든 | 가던 오던 | 선택 |

---

## 9. 세요/셔요 구분

### 규칙
- **세요**: '-시어요'의 준말 (표준어)
- **셔요**: 비표준

### 예시
| 올바른 표현 | 틀린 표현 |
|------------|----------|
| 가세요 | 가셔요 |
| 하세요 | 하셔요 |
| 드세요 | 드셔요 |
| 오세요 | 오셔요 |

---

## 10. 습니다/읍니다

### 규칙
- **습니다**: 현대 표준어
- **읍니다**: 옛 표기 (현재 비표준)

### 예시
| 올바른 표현 | 틀린 표현 |
|------------|----------|
| 합니다 | 합읍니다 |
| 갑니다 | 갑읍니다 |
| 있습니다 | 있읍니다 |
| 없습니다 | 없읍니다 |

---

## 11. 띄어쓰기 - 의존명사

### 규칙
의존명사는 앞말과 띄어 쓴다.

### 자주 틀리는 의존명사
| 의존명사 | 올바른 예 | 틀린 예 |
|---------|----------|---------|
| 수 | 할 수 있다 | 할수있다 |
| 것 | 먹을 것 | 먹을것 |
| 데 | 갈 데 | 갈데 |
| 바 | 아는 바 | 아는바 |
| 리 | 그럴 리 없다 | 그럴리없다 |
| 줄 | 할 줄 안다 | 할줄안다 |
| 지 | 온 지 오래 | 온지오래 |
| 듯 | 할 듯하다 | 할듯하다 |
| 뿐 | 할 뿐이다 | 할뿐이다 |
| 만큼 | 할 만큼 | 할만큼 |

---

## 12. 띄어쓰기 - 보조용언

### 규칙
보조용언은 띄어 쓴다. (붙여 쓰기도 허용되나 띄어쓰기 권장)

### 예시
| 권장 표현 | 허용 표현 |
|----------|----------|
| 먹어 보다 | 먹어보다 |
| 해 버리다 | 해버리다 |
| 알아 가다 | 알아가다 |
| 읽어 내다 | 읽어내다 |
| 써 주다 | 써주다 |

---

## 13. 어/오 구분

### 규칙
- 양성모음(ㅏ,ㅗ) + 아/아서
- 음성모음(ㅓ,ㅜ,ㅡ,ㅣ) + 어/어서

### 예시
| 올바른 표현 | 틀린 표현 |
|------------|----------|
| 잡아서 | 잡어서 |
| 먹어서 | 먹아서 |
| 와서 | 왔어서 |
| 가서 | 갔어서 |

---

## 14. 중복 표현

### 자주 쓰이는 잘못된 중복
| 잘못된 표현 | 올바른 표현 | 이유 |
|------------|------------|------|
| 역전앞 | 역전 또는 역 앞 | 역전=역 앞 |
| 처음 시작 | 시작 | 시작=처음 |
| 제일 가장 | 가장 또는 제일 | 중복 |
| 미리 예방 | 예방 | 예방=미리 막다 |
| 다 모두 | 모두 | 중복 |
| 갑자기 돌연 | 돌연 또는 갑자기 | 중복 |

---

## 15. 사이시옷

### 규칙
순우리말 또는 순우리말+한자어 합성어에서 사이시옷 사용

### 예시
| 올바른 표현 | 틀린 표현 |
|------------|----------|
| 나뭇잎 | 나무잎 |
| 깻잎 | 깨잎 |
| 곳간 | 곡간 |
| 숫자 | 수자 |
| 횟수 | 회수 (구분 필요) |
| 셋집 | 세집 |

### 예외 (한자어+한자어는 6개만)
곳간, 셋방, 숫자, 찻간, 툇간, 횟수

## 16. 형용사/동사 혼동

### 예시
| 올바른 표현 | 틀린 표현 | 설명 |
