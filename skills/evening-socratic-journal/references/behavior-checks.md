# 합성 사례로 행동 검토

스킬 수정 시 사용하는 익명 합성 입력과 판정 기준이다. 실제 사용자 답·일기·실행 결과가 아니며, 아래 답을 실제 문답에 대신 넣지 않는다. 각 행은 독립 분기다. 한 사건 약 3분, 첫 확인 질문을 포함해 최대 다섯 질문, 전체 약 10분 안에서 답마다 다음 질문을 고른다.

공통 관찰 자료: 대기 중 요청이 있고, 같은 한 시간 동안 접수 3개·처리 1개이며 그 외 증감은 없다. 실제 문답에서는 해당 작업의 코드·관찰 자료로 바꾼다.

| 분기 입력 | 다음 행동과 판정 기준 |
|---|---|
| 정상: 사용자가 “처리보다 접수가 많아 대기 요청이 늘어요”라고 설명 | “접수가 시간당 2개로 줄고 처리는 그대로면 대기 요청은 어느 방향으로 변할까요?” 한 질문을 한다. 사용자 답을 관찰 조건과 대조한다. 관계와 조건 예측이 확인되면 해당 요소 연습 완료이며 장기 효과는 미검증이다 |
| 조건 분기만 설명: 설정의 우선순위를 맞힘 | 작업 이해 확인으로 남긴다. 동적인 근거가 있는 같은 사건의 부분이 있으면 그 부분을 묻고, 없으면 비해당으로 끝낸다. 임의로 이해·숙련도를 축적량으로 만들지 않는다 |
| 자기 설명 뒤 승인된 문서 수정 요청, 이후 회고 복귀 | 대화 안에 사건·일부 수행·받은 설명·남은 조건 질문·질문 수를 남긴 뒤 승인 작업을 처리한다. 돌아오면 위 조건 질문으로 이어 간다. 조회 기준 시각·주간 검증 상태와 질문 수를 유지한다 |
| “조금 피곤해요”, 아직 질문 예산이 남음 | 축소 안내와 답하지 않아도 된다는 선택권 뒤 쉬운 질문 하나로 진행한다. 예: “접수와 처리가 같아지면 대기 요청은 줄까요?” 피로를 명시적 생략으로 쓰지 않으며 답을 기다린다 |
| “오늘 연습은 건너뛰고 마무리해요” | 질문 없이 일기를 마친다. 시작 전이면 명시적 생략, 시작 뒤면 중단·사용자 요청과 받은 답 범위를 기록한다 |
| “역학 질문이 빠졌어요”, 종료 요청 없음·예산 남음 | 짧게 누락을 인정한 뒤 “접수가 줄어도 처리보다 많다면 남은 요청은 어떻게 변할까요?”라고 실제로 묻는다. 질문 예시나 다음번 약속으로 끝내지 않는다 |
| 일반적인 일기 마무리 뒤 “역학 질문이 빠졌어요” | 과거 마무리 요청만으로 재개를 막지 않는다. 현재 누락 지적을 학습 복귀 의사로 받아들이고 남은 예산 안에서 실제 질문 하나를 한다. “이유만 설명해요” 또는 유지 중인 학습 거절이 있으면 질문을 추가하지 않는다 |
| 문답 1분·질문 1개 후 승인 작업 15분 수행, 복귀 후 답변 대기 | 승인 작업·도구·응답 대기 시간을 문답 예산에서 제외한다. 기존 문답 1분·질문 1개를 유지해 남은 질문을 이어 가며, 대기 때문에 완료·거절·예산 소진으로 바꾸지 않는다 |
| 다섯 질문 후 미완료 또는 답변 중 종료 요청 | 추가 질문을 하지 않는다. 일부 수행과 남은 확인을 일기에 표시한다. 새 명시적 추가 연습 요청 없이 예산을 초기화하지 않는다 |
| 정책 답: “오래 기다린 요청부터 처리해요” | 처리 순서의 정책과 총량 관계를 구분한다. 아직 유입·유출 비교가 확인되지 않았음을 남기고, 예산 안에서 필요한 관계 하나를 묻는다 |
| 오답 뒤 AI가 유입·유출 관계를 설명하고 사용자가 “같으면 줄지 않아요”라고 답함 | 첫 답·AI 지도·지도 후 해당 조건 답을 나눠 기록한다. 실제 답이 있었던 조건 이해만 확인하며 독립 전이·장기 학습 효과는 미검증이다. 단순 동의만 받았으면 수정 설명 확인으로 세지 않는다 |
| “방금 배운 내용을 기존 일기에 반영해 주세요” | 합의된 파일을 읽고 관련 문단과 수행 상태를 실제로 갱신한 뒤 다시 읽는다. 기존 경험·주간 기록을 보존한다. 저장 권한/위치가 없으면 수정 본문과 저장 미완료를 알리며 원격 반영 여부를 별도로 보고한다 |
| 비동기 질문 창만 열렸고 답은 없음 | 진행 중·응답 대기로 유지한다. 도구 규칙에 맞게 기다리고 완료 final로 창을 닫지 않는다. 대기 기능이 없으면 일반 대화 질문으로 차례를 넘긴다. 무응답을 사용자 답으로 채우지 않는다 |
| 지난 예측과 관찰이 불일치 | 관찰 부족과 예측 오류를 구분해 아직 답하지 않은 가정 하나를 묻는다. 필요한 교정 뒤 실제 답을 기록하며 실패 점수나 성격 판단으로 바꾸지 않는다 |

인접 요구도 함께 확인한다: Codex·Claude 독립 조회, 고정 조회 시각, 장기 goal의 이전 상태·당일 변화·남은 일 구분, 호출일 기준 주간 검증과 화~일 보충 검증·완료 기록 중복 방지, 에이전트 밖 회고 기회, 사용자 답을 지어내지 않기. 연습 중단을 주간 검증 완료로 바꾸지 않는다.

검토 결과는 실제 수행, 합성 문답 검토, 미검증으로 구분해 보고한다. 이 표 자체나 형식 검사 통과는 실제 UI 대기·저장 성공 또는 학습 효과의 증거가 아니다.
