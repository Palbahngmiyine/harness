## Basis and deliberate policy choices

- [Haskell and research sources](../references/functional-programming.md): Hughes supports composition; Haskell Report distinguishes actions from execution; State Threads supports type-enforced encapsulation, not automatic C/Rust purity; Turner distinguishes totality/productivity.
- The former type-only mutation admission is explicitly refined into a reviewed, approved kernel contract. Audited/trusted C/Rust code is labelled weaker evidence than runST's type-enforced encapsulation. Domain specifications remain immutable; this PR does not approve an arbitrary downstream kernel.
- C evidence uses the official C11 committee draft plus the project's actual pinned compiler contract, not a claim that the draft is the latest ISO standard.
- Rust ownership, Fn, interior mutability, Drop, and Arc documentation determine the language-specific cautions. Aeneas/Frama-C are proposed verification routes, not tools executed in this review.
- OpenAI guidance motivates conditional loading, explicit authority, and matched evaluation. No paper establishes that the recursive engineering process converges or improves coding-agent performance.

## Limits and next-cycle trigger

No Frama-C, Aeneas, Miri, Rust sanitizer, TSan/MSan, all-platform matrix, production C/Rust FFI suite, or paid/model-controlled LLM evaluation was run here. Their applicability belongs to actual consuming code and its declared verification gates; they are not silently marked passed.
The checker covers the package's inline local links and simple ATX fragments, not arbitrary Markdown/HTML, external link availability, semantic translation equivalence, or proof soundness. Review changes to the checker/registry as policy changes; no self-edited checker can independently certify its own semantics.
Native probes contain explicitly labelled, legal impurity counterexamples. They demonstrate why the contracts are necessary; they do not analyze arbitrary user programs. The review did not execute a data race to infer safety from lack of a crash.
Reopen a bounded cycle when a new reproducible failure, language/tool change, or incompatible contract change appears. Retain the accepted parent, regression corpus, evidence, and rollback path. A clean scoped recheck is not a guarantee against every future issue.
