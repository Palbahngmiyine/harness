# 근거 기반 재귀적 개선

[영문 원본](evolution.md)이 기준이다. [공통 규칙](../AGENTS.md)·[검증](verification.md)과 함께 적용한다. 공개 시작 사례: [평가 코퍼스](../evals/cases.json).

**EVO-001** 재귀적 개선은 코드·계약·지침에 한도가 있는 제안/검사/검토를 반복하는 것이다. 자율적 자기수정·배포·병합·사용자 목표 변경 권한이 아니다. 제안은 승인·채택 전까지 불변 검토 데이터다. 함수 재귀·고정점 의미론·이 개발 절차는 다른 개념이다. Haskell 논문이 이 절차의 수렴이나 에이전트 향상을 증명하지 않는다.

**EVO-002** 후보별로 부모 커밋·합의 요구·규칙 ID·판정 기준·입력 코퍼스·언어/도구·승인 범위를 고정한다. 반증 가능한 가설 하나와 유한 예산을 정한다. 기본값은 작업당 실질적 수정 3회다. 후보를 평가하기 전에 기준 결과와 불확실성을 기록한다.

**EVO-003** 작고 안정된 계약과 순수 참조 관계를 기준으로 모듈을 변경한다. 한 번에 원인 하나를 바꾸고 공개 값·오류/상태/효과 이력·자원 의무를 비교한다. 호환 구현은 계약 뒤에서 반복 개선할 수 있다. 계약 변경은 승인·하위 호환 검토가 필요한 버전 있는 마이그레이션이며 숨은 리팩터링이 아니다.

**EVO-004** 공격·방어 검토를 분리한다. 공격은 규칙 ID·반례·심각도·근거·재현 절차를 제출하고 방어는 동의가 아니라 근거로 재현하거나 반박한다. 수정마다 변경 영역과 인접 불변식을 다시 검사한다. 단일 모델의 순차 자기검토·별도 세션·별도 에이전트·사람 검토 중 실제 방식을 기록하고 독립성을 지어내지 않는다.

**EVO-005** 후보 평가 중 기존 평가기/정답 기준을 고정한다. 통과를 위해 회귀 삭제·임계값 완화·제외 변경·비공개 평가 문제 편집·미지원 검사 재분류를 하지 않는다. 평가기 자체 오류라면 먼저 결함을 기록하고 별도로 승인/버전 관리한 뒤 같은 수정 평가기로 기준과 후보를 재실행한다. 약한 계약은 재귀 최적화가 아니라 명시적 사용자 승인이 필요하다.

**EVO-006** 지침 변경이 코딩 에이전트 효과를 높인다는 주장에는 공개 개발 회귀와 독립적으로 제공된 비공개 평가 작업을 요구한다. 모델 스냅샷·추론 설정·도구·저장소 상태·예산을 맞추고 반복 실행과 편차를 보고한다. 정확성·순수성 위반·권한 위반·근거 보고의 진실성·코드/추상화 증가·비용을 측정한다. 변하지 않은 필수 품질 게이트를 통과한 후보끼리만 비용을 비교한다. 코퍼스 존재나 검사기 테스트는 LLM 평가 실행이 아니다. 정확성/문서 수정은 에이전트 벤치마크 없이 범위에 맞는 게이트로 검토할 수 있지만 성능 영향은 미검증으로 남긴다. 측정된 개선을 주장하거나 승인 없이 평가 서비스를 구매하지 않는다.

**EVO-007** 승인 범위 안에서 명시한 검토 범위의 미해결 발견과 알려진 필수 계약 회귀가 없는 후보만 채택한다. 반례·명령·결과·출처·정확한 커밋을 보존한다. 전체 범위 재검사에 문제가 없으면 멈추며 회차를 채우려고 통과한 후보를 바꾸지 않는다. 후보 반복·진전 없음·미해결 상태의 예산 소진은 무한 루프나 조용한 완화가 아니라 차단 사유로 보고한다.

**EVO-008** 채택된 부모·롤백 계획·가설/근거/판정/한계 기록을 보존한다. 새 근거가 생기면 재현 사례를 추가하고 새 유한 개선 주기를 시작한다. 영향받는 호출자·번역·문서·검사기를 재검토한다. 번역 ID와 의미를 동기화한다. ID는 추적성이지 의미 동등성 증명이 아니다.

**EVO-009** 커널·프로파일 승인 전 숨은 C 별칭·출력 버퍼 쓰기·Rust 내부 가변성·효과 콜백/소멸자·즉시 액션 실행·오버플로·비종료·외부 결과 불명·평가기 조작·잘못된 문서 로딩을 검사한다. 정상적인 불변 클로저·값 함수도 허용되는지 확인해 과도한 규칙이 유리해지지 않게 한다.

**EVO-010** 유지보수 기록은 실제 실행·읽기 검토만 수행한 항목·범위 밖·미검증을 구분한다. 범위 내 문제가 없다는 검토는 미래 코드 전체 보장·형식 증명·코딩 에이전트 향상 실증이 아니다. 대응 실행과 결과 보존 없이 벤치마크 향상을 발표하지 않는다.
